# IA: skills, plugins, specs e mods

Projetos para o Claude Code, em português do Brasil. Cada pasta é um projeto com o seu próprio README: o problema que ele resolve, a solução e o bê-á-bá de instalar e usar.

Esta é uma amostra daquilo que curamos, adaptamos e criamos na [Mentoria Fábrica de Apps](https://www.joviano.com/vitrine/mentoria-fabrica).

## Projetos

| Projeto | Tipo | O que faz |
| --- | --- | --- |
| [eleazar-esquenta-secao](eleazar-esquenta-secao/) | mod | Mantém o cache da conversa quente nas pausas, mostra o estado embaixo da caixa de mensagem e avisa o preço antes de uma mensagem com o cache frio. |

## Como instalar um projeto daqui

Este repositório é um marketplace do Claude Code. No app desktop (aba Code), clique no **+** ao lado da caixa de mensagem, abra **Plugins** e adicione o marketplace `jovianosilveira/ia-skills-plugins-specs-mods`. Depois é só escolher o projeto.

Pelo terminal do sistema:

```bash
claude plugin install <projeto> --marketplace jovianosilveira/ia-skills-plugins-specs-mods
```

O README de cada projeto traz o passo a passo completo.
